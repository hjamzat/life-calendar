Make it update every day

iPhone — Shortcuts

  1. Copy the URL above.
  2. Open Shortcuts → Automation → + → Time of Day. Pick a time just after midnight, Daily, and Run Immediately.
  3. Add the action Get Contents of URL and paste the URL.
  4. Add Set Wallpaper Photo (older iOS: Set Wallpaper), choose Lock Screen, and turn off Show Preview and Crop to Subject.
  5. Tap the play button once to check it.

Android

  1. Copy the URL above.
  2. In an automation app (Tasker, MacroDroid or a "wallpaper from URL" app), create a daily task that downloads the URL.
  3. Set the downloaded image as the lock-screen (or home) wallpaper.

Dates computed with the Umm al-Qura calendar via the browser's Intl API. Font: Inter (SIL OFL).
